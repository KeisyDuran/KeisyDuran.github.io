// lo que hago

Cuatro sombreros, un mismo sistema.

En mis proyectos no le paso el trabajo a otro equipo: soy quien modela los datos, quien diseña la pantalla, quien busca los errores y quien publica. Elige un rol para ver qué he hecho en cada uno.

Backend

Es mi especialidad. APIs REST, modelado relacional, procedimientos almacenados y seguridad pensada desde el código.

  • C#
  • ASP.NET Core MVC
  • Web API
  • .NET 9
  • EF Core
  • SQL Server · T-SQL
  • PostgreSQL · Prisma
  • JWT
  • LDAP
  • Redis
  • Tour Manager Pro 120 endpoints REST en 30 módulos sobre 35 entidades, con datos aislados por agencia, 4 roles, auditoría y límite de peticiones.
  • Tour Manager Pro Pagos con AZUL (CardNet), suscripciones con PayPal y comprobantes fiscales de la DGII (NCF, reportes 606 y 607).
  • Inventario de Servidores Controladores y servicios para servidores, racks, virtualizadores, almacenamiento, licencias y reemplazos, con inicio de sesión contra Active Directory.
  • LexisCampus DMS Arquitectura Onion en .NET 8, versionado de documentos y huella SHA-256 para verificar autenticidad.
  • Módulo de solicitudes del SGA APIs en ASP.NET sobre procedimientos almacenados de SQL Server.

Frontend

Interfaces que la gente usa todos los días: claras, rápidas y adaptables al celular. Me importa que se vean bien y que no confundan.

  • React
  • Next.js
  • TypeScript
  • Tailwind CSS
  • Razor
  • .NET MAUI
  • Bootstrap
  • Diseño responsive
  • i18n
  • Tour Manager Pro La página comercial, el catálogo público con los colores y el logo de cada agencia, y un panel de 21 pantallas. Todo en 5 idiomas.
  • Tour Manager Pro Inscripción y pago en línea, código QR para compartir y reportes imprimibles o en Excel.
  • LexisCampus DMS Panel administrativo, carga de documentos, expediente del estudiante y portal público de verificación en React con Vite.
  • Próspera App de finanzas personales con gráficos (Recharts), navegación para móvil y una identidad visual propia.
  • Punto de Venta App para Android y Windows con .NET MAUI y patrón MVVM: catálogo, carrito, cobro y ticket.

QA y pruebas

Pruebo lo que construyo antes de que llegue a un cliente, y sé hacerlo de forma formal: casos de prueba, defectos documentados y criterios de aceptación.

  • Vitest
  • Pruebas unitarias
  • Casos de prueba
  • Azure DevOps
  • Postman
  • Swagger
  • Criterios de aceptación
  • Tour Manager Pro Más de 600 pruebas automatizadas sobre la lógica delicada: precios, cobros, cupos y comprobantes.
  • Tour Manager Pro Ningún despliegue sale sin pasar la verificación de tipos, el lint, las pruebas y el build.
  • Tour Manager Pro Encontré y corregí errores que costaban dinero, como una habitación que se cobraba dos veces o un suplemento individual que no se aplicaba.
  • Pasantía QA · Registro Inmobiliario Casos de prueba y reportes de defectos para SAVA, SGA y el asistente virtual ARI en Azure DevOps.
  • Inventario de Servidores Detección de duplicados en la importación masiva y validación de cada operación contra la auditoría.

Infraestructura

Antes de programar administraba servidores. Por eso desarrollo pensando también en dónde va a correr el software y en cómo se mantiene.

  • IIS
  • Windows Server
  • VMware · Hyper-V
  • Active Directory
  • PowerShell
  • Exchange · M365
  • Vercel
  • Docker
  • Inventario de Servidores Publicado en IIS sobre Windows Server con conexión cifrada.
  • Tour Manager Pro En Vercel con dominio propio y HTTPS, base de datos en Supabase, migraciones controladas y cabeceras de seguridad (CSP).
  • LexisCampus DMS Entorno local con Docker Compose: SQL Server 2022 y MinIO (S3).
  • Registro Inmobiliario Servidores físicos y virtuales con alta disponibilidad, y automatización con PowerShell sobre Active Directory y Exchange.
