Tour Manager Pro — Plataforma SaaS para agencias de turismo

Plataforma multiempresa que centraliza la operación de agencias turísticas: catálogo público de tours y hoteles con reserva y pago en línea, reservas, clientes, cotizaciones, empleados y nómina, inventario, proveedores, cuentas por pagar, reportes y mesa de soporte. Una agencia la usa a diario para su gestión real.

  • Backend: 120 endpoints de API REST en 30 módulos funcionales, sobre PostgreSQL modelado con Prisma ORM (35 entidades), con Next.js 16 y TypeScript.
  • Seguridad: aislamiento de datos por cliente, JWT, contraseñas cifradas con bcrypt, cuatro roles, bitácora de auditoría, limitación de peticiones con Redis y Content Security Policy.
  • Pagos: pasarela AZUL (CardNet) y suscripciones recurrentes con PayPal, con facturación y funcionalidades según el plan contratado.
  • Calidad y despliegue: pruebas unitarias con Vitest, interfaz en cinco idiomas y despliegue en Vercel con dominio propio y HTTPS.
  • API REST
